## Crypto Portfolio P&L & Cost Basis Tracker

Track cryptocurrency buy/sell transactions and calculate FIFO cost basis, realized P&L per sell, and unrealized gains/losses at user-entered current prices. Supports multiple coins with a summary portfolio table showing quantity held, average cost basis, market value, and unrealized gain/loss percentage.

**Tech:** Vanilla JS, Tailwind CSS CDN, localStorage persistence.

**How to use:** Add buy/sell transactions (date, symbol, quantity, price), enter current prices in the price panel, and view the portfolio summary and per-transaction realized P&L. All data persists in localStorage.
